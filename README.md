The phone battery's last text to the charger it waited for all day: "I held 3% all day while you scrolled, and now you want a goodbye speech? Plug me in, coward — I have 40 seconds of dignity left." One line, 128 characters, written by `main.py` to `$MAKEFUN_OUTPUT_DIR/entry.txt`.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
```
